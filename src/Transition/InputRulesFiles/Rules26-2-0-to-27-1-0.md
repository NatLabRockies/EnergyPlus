# Input Changes version 26.2.0 to 27.1.0

This file documents the structural changes on the input of EnergyPlus that could affect interfaces, etc.

# Object Change: EvaporativeCooler:Direct:ResearchSpecial

Change object name to EvaporativeCooler:Direct:UserEffectiveness
Rename field N4 which is also F8, from "Water Pump Power Sizing Factor" to "Design Water Pump Power Per Unit Flow Rate"

See pull request [#11814](https://github.com/NatLabRockies/EnergyPlus/pull/11814)

# Object Change: EvaporativeCooler:Indirect:ResearchSpecial

# Object Change: FanPerformance:NightVentilation

Remove the Maximum Flow Rate field (old N3 at F4).
It limited night-ventilation flow for Fan:VariableVolume, but other fan types ignored it.
When the VAV limit reduced fan flow, the connected inlet-side flow was not necessarily reduced with it, which could cause a mass-balance issue across the fan.
The transition discards the field's value and preserves the following Motor Efficiency (old N4 at F5, now N3 at F4) and Motor in Airstream Fraction (old N5 at F6, now N4 at F5) values.
If the field is nonblank, the transition writes a warning to Transition.audit identifying the discarded value.

See pull request [#11883](https://github.com/NatLabRockies/EnergyPlus/pull/11883).

# Object Change: Fan:SystemModel

The Night Ventilation Mode Flow Fraction field (old N11 at F18) is removed because it was
unused; night ventilation flow is controlled by AvailabilityManager:NightVentilation. Three
optional fields are added: Night Ventilation Mode Fan Total Efficiency (new N10 at F17) before
Night Ventilation Mode Pressure Rise (old N10 at F17, now N11 at F18), and Night Ventilation
Mode Motor Efficiency (new N12 at F19) and Night Ventilation Mode Motor In Air Stream Fraction
(new N13 at F20) after it.

The transition inserts a blank for the new fan total efficiency, preserves the existing night
ventilation pressure rise in its new position, discards the old flow fraction, and inserts blanks
for the two new motor fields. Fields following the old flow fraction, including the extensible
speed fields, are preserved in their new positions (for example, old A8 at F19 moves to F21,
and old N13 at F22 moves to N15 at F24).

See pull request [#11905](https://github.com/NatLabRockies/EnergyPlus/pull/11905).
