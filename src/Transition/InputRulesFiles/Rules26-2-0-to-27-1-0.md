# Input Changes version 26.2.0 to 27.1.0

This file documents the structural changes on the input of EnergyPlus that could affect interfaces, etc.

# Object Change: EvaporativeCooler:Direct:ResearchSpecial

Change object name to EvaporativeCooler:Direct:UserEffectiveness
Rename field N4 which is also F8, from "Water Pump Power Sizing Factor" to "Design Water Pump Power Per Unit Flow Rate"

See pull request [#11814](https://github.com/NatLabRockies/EnergyPlus/pull/11814)

# Object Change: EvaporativeCooler:Indirect:ResearchSpecial

Change object name to EvaporativeCooler:Indirect:UserEffectiveness
Rename field N4 which is also F7, from "Water Pump Power Sizing Factor" to "Design Water Pump Power Per Unit Flow Rate"

See pull request [#11814](https://github.com/NatLabRockies/EnergyPlus/pull/11814)

# Object Change: FanPerformance:NightVentilation

Remove the Maximum Flow Rate field.
It limited night-ventilation flow for Fan:VariableVolume, but other fan types ignored it.
When the VAV limit reduced fan flow, the connected inlet-side flow was not necessarily reduced with it, which could cause a mass-balance issue across the fan.
The transition discards the field's value and preserves the following Motor Efficiency and Motor in Airstream Fraction values.
If the field is nonblank, the transition writes a warning to Transition.audit identifying the discarded value.

# Object Change: ZoneControl:Thermostat

Last field (N1 at F12) moved to F4 as N1

See pull request [#11822](https://github.com/NatLabRockies/EnergyPlus/pull/11822)
