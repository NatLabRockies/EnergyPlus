# Object Change: Material

Append three optional numeric fields:

- N8, "Thermal Absorptance Inside Face"
- N9, "Solar Absorptance Inside Face"
- N10, "Visible Absorptance Inside Face"

When any new field is blank, its value is inherited from the corresponding existing absorptance field. Existing input files therefore retain their prior bulk-material behavior without modification. When a new field is entered, the corresponding existing field supplies the outside-face value and the new field supplies the inside-face value.

See pull request [#11750](https://github.com/NatLabRockies/EnergyPlus/pull/11750)

# Object Change: Material:NoMass

Append three optional numeric fields:

- N5, "Thermal Absorptance Inside Face"
- N6, "Solar Absorptance Inside Face"
- N7, "Visible Absorptance Inside Face"

The inheritance and face-specific behavior are the same as for the `Material` object. Existing fields are not renamed or reordered.

See pull request [#11750](https://github.com/NatLabRockies/EnergyPlus/pull/11750)

# Object Change: MaterialProperty:VariableAbsorptance

Append five optional alpha fields:

- A8, "Control Signal Inside Face"
- A9, "Thermal Absorptance Function Name Inside Face"
- A10, "Thermal Absorptance Schedule Name Inside Face"
- A11, "Solar Absorptance Function Name Inside Face"
- A12, "Solar Absorptance Schedule Name Inside Face"

The existing control and function/schedule fields continue to control the outside face. When A8 is blank, the inside-face absorptances remain at the constant values defined by the referenced material; they do not follow the outside-face variable controls. Existing fields are not renamed or reordered.

See pull request [#11750](https://github.com/NatLabRockies/EnergyPlus/pull/11750)

# Object Change: Space

Insert new field A4 "Construction Assignment Set Name" (blank by default) before the existing extensible Tag fields (A4/A5/A6 → A5/A6/A7).

See pull request [#11755](https://github.com/NatLabRockies/EnergyPlus/pull/11755)
