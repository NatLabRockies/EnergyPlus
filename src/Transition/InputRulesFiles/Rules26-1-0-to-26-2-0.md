Input Changes version 26.1.0 to 26.2.0
======================================

This file documents the structural changes on the input of EnergyPlus that could affect interfaces, etc.

# Object Change: Coil:Cooling:DX:CurveFit:OperatingMode

Insert new field A2 which is also F9, "Apply Part Load Fraction to Speeds Greater than 1", defaulted to No

See pull request [#11448](https://github.com/NatLabRockies/EnergyPlus/pull/11448)

# Object Change: ElectricEquipment and new ElectricEquipment:Definition

The object was split into two: `ElectricEquipment` and `ElectricEquipment:Definition`.

The following fields were moved from `ElectricEquipment` to the new `ElectricEquipment:Definition` object:
- old A4 `Design Level Calculation Method` → new A2 in `ElectricEquipment:Definition`
- old N1 `Design Level` → new N1 in `ElectricEquipment:Definition`
- old N2 `Watts per Floor Area` → new N2 in `ElectricEquipment:Definition`
- old N3 `Watts per Person` → new N3 in `ElectricEquipment:Definition`
- old N4 `Fraction Latent` → new N4 in `ElectricEquipment:Definition`
- old N5 `Fraction Radiant` → new N5 in `ElectricEquipment:Definition`
- old N6 `Fraction Lost` → new N6 in `ElectricEquipment:Definition`

The remaining `ElectricEquipment` fields are renumbered as follows:
- old A2 `Zone or ZoneList or Space or SpaceList Name` → new A3
- old A3 `Schedule Name` → new A4
- old A5 `End-Use Subcategory` → new A5 (unchanged)

A new field is inserted in `ElectricEquipment`:
- new A2 `Electric Equipment Definition Name` — references the new `ElectricEquipment:Definition` object

For transition: create one `ElectricEquipment:Definition` object per `ElectricEquipment` instance (or share definitions where the definition fields are identical), populate it with the moved fields, and set the new A2 field in `ElectricEquipment` to reference it.
