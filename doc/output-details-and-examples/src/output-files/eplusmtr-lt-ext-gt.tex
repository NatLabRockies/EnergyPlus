\section{eplusmtr.\textless{}ext\textgreater{}}\label{eplusmtr.ext}

The eplusmtr.csv (or txt or tab extension) is a file that can be produced with OutputControl:Files or by post-processing on the eplusout.mtr file. EnergyPlus installs the ReadVarsESO postprocessor from the readvars Python package; use the -r or --readvars command-line option to run it after a simulation.
